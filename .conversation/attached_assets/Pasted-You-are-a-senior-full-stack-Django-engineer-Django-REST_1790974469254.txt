You are a senior full-stack Django engineer, Django REST Framework architect, UI/UX designer, security-conscious backend developer, and QA engineer.

Build a complete, functional web application called **VivaBot**.

Do NOT create only a frontend mockup. I want a real working application with authentication, database persistence, file uploads, REST APIs, AI integration, viva session management, answer evaluation, history, validation, and a polished student-friendly UI.

## PRODUCT IDEA

VivaBot is an AI-powered platform that helps college students prepare for their project vivas.

The main workflow is:

1. Student creates an account or logs in.
2. Student creates a project.
3. Student enters basic project information and uploads their project report.
4. Backend extracts useful text from the uploaded report.
5. Google Gemini API analyzes the actual project content.
6. Gemini generates viva questions specifically about that student's project.
7. A Viva Session begins.
8. Questions are shown one at a time.
9. Student types an answer.
10. The answer is evaluated by Gemini using the project context and question.
11. Student receives:

* score
* feedback
* strengths
* missing points
* suggested/improved answer

12. After completing the viva, the student receives an overall result.
13. Previous projects and viva sessions remain available in History.

The important idea is:

**VivaBot must NOT generate generic Computer Science viva questions. Questions must be derived from the student's actual uploaded project/report.**
